# Job Application Tracker

A web-based job application management system built with Python and Flask. This project helps users organize their job search, track applications, manage interviews, and monitor application progress in one place.

## Features

- **Dashboard:** View application statistics and job search progress.
- **Application Tracking:** Add and manage job applications.
- **Interview Management:** Schedule and track upcoming interviews.
- **Reminders:** Create reminders for important job search tasks.
- **Activity Timeline:** Track application submissions, interview scheduling, and status changes.
- **Application Insights:** View application response rates, success rates, and average employer response times.
- **Quick Actions:** Quickly access important job search functions.

## Technologies Used

- HTML5

## Installation

1. Clone the repository:

```bash
git clone https://github.com/JordynF-design/Job-Application-Tracker.git
```

2. Navigate into the project folder:

```bash
cd Job-Application-Tracker
```

3. Create a virtual environment:

```bash
python3 -m venv venv
```

4. Activate the virtual environment:

```bash
source venv/bin/activate
```

5. Install Flask:

```bash
pip install Flask
```

6. Start the application:

```bash
python app.py
```

7. Open your browser and visit:

```text
http://127.0.0.1:5001
```
